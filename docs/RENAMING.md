# Renaming Tidy

The name is provisional. Every place it appears, so a rename is one pass:

- [ ] `project.yml`: project `name`, target `Tidy`, `PRODUCT_NAME`, `PRODUCT_BUNDLE_IDENTIFIER` (`dev.gustaf.Tidy`),
      `CFBundleDisplayName`, `NSHumanReadableCopyright`, package `TidyCore`
- [ ] `Resources/Info.plist`: `CFBundleDisplayName`, `NSHumanReadableCopyright` (regenerated by xcodegen)
- [ ] `Sources/TidyApp.swift`: file and struct name, update tooltip text
- [ ] `Sources/AppUpdater.swift`: `releasesURL` and download URL (`gustaferiksson/tidy`), `requirement` identifier
      (`dev.gustaf.Tidy`), `Tidy-<version>.zip`, `Tidy.zip`, `Tidy.app`, staging prefix `.tidy-update-`, swap script
      name `tidy-update-*.sh`, backup suffix `.tidy-old`, alert strings
- [ ] `Sources/AppSettings.swift`: snapshot defaults suite `dev.gustaf.Tidy.snapshot`
- [ ] `Sources/SettingsGeneral.swift`, `Sources/SettingsAbout.swift`: user-facing strings
- [ ] `Packages/TidyCore`: package, target, test target and folder names; `--package-path` in `ci.yml`,
      `release.yml`, `build.sh`, `CLAUDE.md`, `.claude/rules/swift.md`
- [ ] `build.sh`: `Tidy.xcodeproj`, scheme, `dist/Tidy.app`
- [ ] `notarize.sh`: `dist/Tidy.app`, `Tidy-<version>.zip`, codesign requirement identifier
- [ ] `.env.example`: `NOTARY_PROFILE=Tidy` (and the notarytool keychain profile itself)
- [ ] `.github/workflows/ci.yml`: `dist/Tidy.app` bundle checks
- [ ] `.github/workflows/release.yml`: `name: Tidy` (sets the zip name), `app: dist/Tidy.app`, `cask: tidy`
- [ ] `icon/tidy.svg` and `SVG=` in `icon/generate-icons.sh`
- [ ] `SHIPPING.md`, `docs/RELEASING.md`, `CLAUDE.md`
- [ ] GitHub repo `gustaferiksson/tidy`
- [ ] `Casks/tidy.rb` in `gustaferiksson/homebrew-tap`

Changing the bundle id or Team ID breaks self-update for existing installs (the updater pins both), and resets
their settings and Launch at login. Do it before the first public release.
